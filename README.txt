FitZone website - folder guide
==============================

Put ALL of these together in one folder (keep the folder names exactly as they are):

  index.html        the page structure (open this file in the browser)
  styles.css        all the styling
  script.js         all the logic (the pictures are connected here by file name)
  hero/             Home hero animation (108 files: body, poster, L-00..L-52, R-00..R-52)
  products/         Shop product photos (24 files)
  images/           Home, Classes, Studio, Trainers pictures (44 files)
  video/            Studio tour video (gym-tour.mp4) and its poster picture

Where the picture names are written:
  - index.html : Home / Studio / Programs / About pictures (images/...), studio video (video/...)
  - script.js  : hero frames (hero/...), shop photos (products/...), class photos (images/class-*.webp),
                 trainer photos (images/trainer-*.webp)
  - styles.css : hero poster (hero/poster.webp)

Important: do not rename the picture files or folders. If you rename one, change the same name in the code too.
